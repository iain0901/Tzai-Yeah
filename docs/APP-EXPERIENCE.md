# 載耶手機小世界

2026-11-14 將公開前台改為單一視窗 App 體驗。原有 API、權限、資料庫、NFC token 與後台不變。

## 使用方式

- 底部「邀請／活動／小卡」直接切換畫面；活動後「邀請」改為「回憶」。
- 愛心持續浮動，點按會彈跳、散出星星並輪換暖心訊息。
- 薑餅人搖擺與跳躍；禮物搖晃，點按會打開三幕邀請。
- 拼圖環繞、流星光點、燈串呼吸與背景亮點獨立運動；點「你的聖誕小世界」切換燈串節奏。
- 小卡可點按翻面。活動當天使用已發布分組，首次進入小卡畫面播放揭曉，之後直接顯示結果。
- 邀請動畫可手動換幕或直接查看資訊；設定 YouTube 網址後首頁增加直式預告入口，仍保留邀請動畫。
- 活動票券提供行事曆與地圖。長組名、集合地點、小提醒和個人簡介可點開閱讀分頁。
- 個人小卡以名字、簡介、連結三步編輯；鍵盤縮小可用高度時，表單內容可局部捲動，操作列保留。
- 音效預設關閉，使用者開啟後僅在點按角色時發聲。選單可暫停畫面動態，亦尊重系統減少動態偏好。

## 本機驗證

- TypeScript 與修改元件的 ESLint 錯誤檢查。
- 390×844、375×667、320×568 實際瀏覽器檢查：文件寬高等於視窗，主畫面沒有捲軸，底部導覽完整可見。
- 點愛心回應、薑餅人問候、開禮物、自動三幕與手動換幕、切換活動票券、卡片翻面。
- 當天分組自動揭曉、重播、結果與活動後紀念卡；示範資料不寫入正式活動。
- 本機已認領 QA 卡登入、三步切換、既有內容載入。未修改正式參加者資料。
- 暫停動態後 DOM 中所有動畫均停用，畫面內容與按鈕仍可見。
- 瀏覽器未出現前台 JavaScript 錯誤或 hydration 警告。
