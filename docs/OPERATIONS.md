# 載耶 2026｜工作人員操作手冊

後台入口為 `/admin`。使用本機管理員帳號登入。首次帳密存放於 `secrets/admin-login.txt`；詳見 [自架手冊](SELF-HOSTING.md)。

## 人員名單：發送專屬連結

1. 到「人員名單」新增參加者，或以 UTF-8 CSV 匯入。活動組別可以先在「分組名單」建立，再由人員名單指定。
2. 在姓名所在列按「複製專屬連結」。沒有連結時會先建立；已有有效連結的人會複製原網址。若瀏覽器無法自動複製，畫面會提供可手動複製的網址。
3. 核對姓名，將連結私下傳給本人。請使用正式網站後台複製；本機預覽網址僅供測試。參加者用同一個連結看活動資訊、分組、遊玩及編輯自己的紀念小卡，不需要另外登入。
4. 「查看個人檔案」可核對家別、分組以及參加者已存下的顯示名稱、簡介和連結。

專屬網址的驗證碼由系統隨機產生，不會由姓名、家別或顯示編號推算。網址可重複使用，持有完整網址的人也能操作該人的遊戲和個人內容，因此不要將整份名單或網址公開。

原有小卡連結仍可使用。若另外保留實體 NFC 卡，可將相同專屬網址寫入卡片；寫卡由外部工具處理，這版後台不需先發卡，也沒有報到介面。原先的按家編號表可留在本機做核對，卡套的家內編號仍由每家從 1 開始，與全站唯一的系統卡號分開。

## 匯入人員名單

從「人員名單」按「匯入 CSV」，可下載空白範本。一般匯入只需姓名，可選填家別、家內編號與組別：

```csv
姓名,家別,家內編號,組別
示範甲,第一家,1,暖燈組
示範乙,第二家,1,拼圖組
```

- 家內編號為選填正整數，有填時也需要家別；同一家不可重複。可從人員檔案的「編輯人員」維護，或用 CSV 匯入與匯出。
- 組別填後台已建立的完整名稱或組別 ID；每批最多 500 人。
- 舊版 CSV 若含 `卡號`，它對應一個已存在的全站唯一系統卡號。一般匯入留空即可，之後逐人複製連結。請勿將每家重複的家內編號填入這欄。
- 先看預覽再確認匯入；同名不等於同一人，請用家別核對。相同批次可防止重複匯入，修改過的 CSV 則可能另建資料；既有人員請直接編輯。

「匯出名單」是供核對的報表，不是資料庫備份。真實姓名及連結請留在主辦的本機或私人資料空間。

## 分組名單：先編輯，再發布

工作人員調整的是分組草稿。持卡者看到的是已發布版本，因此改到一半的安排不應立即出現在前台。

1. 在組別及參加者管理中完成分組、集合地點和提醒文字。
2. 檢查所有需要分組的人是否已指定組別。
3. 檢查每組人數，並由另一位工作人員交叉核對關鍵安排。
4. 在「分組名單」按「確認並發布分組」並確認發布，核對發布時間與版本有更新。只要仍有參加者尚未分組，系統就會阻止發布。
5. 若有臨時換組，修改後還要再次發布。連線正常且前台開啟時，約 15 秒內會更新；不用重新發送網址。

「發布分組」和「開放揭曉」是兩件事。可以先發布正確名單，仍讓活動前的持卡者只看到預告和活動資訊。

若要移除組別，到「分組名單」→「編輯」→「移除這個組別」並確認。原組員會在草稿中變成尚未分組；已發布版本暫時保留。先替這些人安排新組別，再重新發布。

## 三個活動階段

後台上方的「活動階段」顯示**目前對外顯示**的階段，並提供三個按鈕。點選要切換的階段即儲存；操作中顯示「正在儲存」，完成後顯示「已儲存，目前對外顯示……」。發生錯誤時會顯示訊息，請確認成功狀態後再通知參加者。階段不會依日期自動切換。

| 階段 | 工作人員設定 | 持卡者體驗 |
| --- | --- | --- |
| 活動前 | 活動前；揭曉關閉 | 活動介紹與邀請動畫；有影片時可主動播放橫向電影預告 |
| 活動中，尚未開放 | 活動中；揭曉關閉 | 等待揭曉的內容，不顯示組別 |
| 活動中，已開放 | 活動中；揭曉開啟；已有已發布分組 | 主畫面顯示這張卡的組別、集合位置與小提醒 |
| 活動後 | 活動後 | 耶誕紀念畫面、回顧文字與外部活動相簿入口 |

階段切換只更新階段欄位，保留影片、相簿、文字與其他設定。「開放分組揭曉」位於「分組名單」，不會隨階段自動開啟。有網路且前台在前景時，約 15 秒內讀取更新；回到頁面也會重新確認。同一專屬網址的主畫面會更新，無須重寫 NFC，也不需要參加者再感應。

發布分組、切到「活動中」、開放「分組揭曉」三個步驟都完成後，才會公布個別組別。修改後保留一個已開啟的持卡者頁面驗證更新。尚未完成分組時，回人員名單檢查配置；參加者應使用包含自己身分的專屬連結。

## 加上 YouTube 電影預告

影片尚未完成時，將預告影片欄位留白，網站使用活動資訊動畫。

影片就緒後，在「頁面設定」→「YouTube 影片網址」貼上單支影片的分享網址，再按「儲存頁面內容」。網站接受常見的 `youtube.com/watch`、`youtu.be`、`youtube.com/shorts` 與嵌入網址，儲存時會驗證影片 ID。

使用者可以點擊播放，活動資訊仍保留在頁面中。播放器以 16:9 橫向容器呈現，YouTube 保留原片比例；電影原有的上下黑邊也會保留，不會放大裁掉畫面。請實際測試影片的分享與嵌入權限；只貼上網址不會更改 YouTube 的影片權限。手機直拿、橫拿及全螢幕播放都應檢查字幕、播放按鈕與關閉播放器是否容易操作。

## 編輯自己的紀念小卡

1. 工作人員在人員名單複製正確參加者的專屬連結。
2. 持卡者從自己的專屬網址進入下方的「小卡」，即可編輯名稱、簡介與個人 HTTPS 連結。
3. 名稱可留白，前台會使用 `#卡號`，例如 `#001`；填入自訂名稱不會改變卡號或網址。
4. 儲存後，從同一個專屬連結回來即可繼續編輯。更換手機也使用同一個網址，不必建立另一個身分。

新版使用卡片 token 驗證編輯權，不要求持卡者登入帳號或輸入認領碼。舊版的認領紀錄保留相容，不是新版發卡與編輯的必要步驟。沒有 token、卡片停用或尚未配對時，不能儲存個人內容。

在原網址後加上 `?edit=1` 可直接進入編輯流程，例如 `https://正式網域/t/卡片代碼?edit=1`。這仍是同一張卡的私人入口，請本人收藏。網址被轉傳時，請通知主辦處理。

## 活動後回顧與個人連結

在「頁面設定」貼上**活動相簿連結**，再填一句回顧文字。網站會提供完整的耶誕紀念畫面，參加者按下「打開我們的回憶」後前往既有照片服務；不需要把整本相簿搬進網站，也不需要逐張上傳。請先以一般參加者身分確認相簿可開啟，再切到「活動後」。

未設定相簿連結時，紀念畫面仍會出現，並顯示回憶整理中的訊息。可選用一張公開 HTTPS 圖片作為封面；不填就使用聖誕插畫。若舊版已有多張照片，第一張用作封面，其餘設定仍保留，前台不做照片輪播。進階設定收在「選填：回顧封面照片」中。

持卡者可從下方的「小卡」編輯與開啟個人連結。外部個人連結只在主動點按時開啟，進站時不會自動跳走，也不會蓋過活動回顧與相簿入口。即使舊資料曾選擇直接開啟連結，進站仍先顯示活動階段的主畫面。

## 本機與正式環境的差異

| 項目 | 本機開發／預覽 | 正式網站 |
| --- | --- | --- |
| 網址 | 通常是 `127.0.0.1` 或 `localhost`，只供開發驗證 | 寫入卡片前確認的長期 HTTPS 網址 |
| 資料庫 | 本機 SQLite，預設放在 `data/tzai.sqlite` | 自己伺服器上的 SQLite；Docker 存在持久化 named volume |
| 登入 | 與正式站相同的本機帳號與密碼驗證 | 工作人員使用自己的管理員帳號；持卡者以小卡 token 使用個人功能 |
| 資料搬移 | 測試卡、名單及分組留在指定的資料庫 | 發布程式不等於搬移資料；使用備份還原或特定匯入功能 |
| 更新 | `npm run dev` 供開發測試 | 重新建置與啟動，啟動時自動套用未執行的遷移 |

資料庫結構變更與名單資料不同：遷移建立或調整資料表；匯入才是新增活動參加者。此專案的結構遷移位於 `drizzle/`，自架版本會在開啟資料庫時套用未執行的遷移。不要把小卡 token、個人資料或本機環境變數一起打包公開。

管理員權限儲存在自己的 SQLite 帳號資料中；一般註冊不會取得後台權限。舊版 `ADMIN_EMAILS`、Sites 身分標頭與模擬帳號不再是這個版本的登入方式。首次管理員帳密、工作階段密鑰與資料備份都應私人保管。

### 正式網站存取權限

自架前台可直接公開閱讀；後台驗證管理員帳號，個人頁編輯則驗證有效且已配對小卡的 token，不需持卡者登入。若反向代理另外設有密碼或來源限制，訪客仍可能在進入網站前被擋下。工作人員自己能開啟，不代表 150 位參加者都能開啟。

正式發卡前，請用沒有工作人員權限的手機或瀏覽器，使用參加者的專屬連結測試。若活動需要任何持卡者直接閱讀資訊，正式主機必須允許這個閱讀範圍；後台驗證管理員帳號，個人編輯驗證有效且已配對小卡的 token。不要為了讓大家看前台而授予後台管理權。

## 發卡前與開場前檢查

完整檢查表位於 `tests/acceptance-checklist.md`。至少完成：

- 正式網域、一般訪客權限、正式資料庫及工作人員帳號都驗證過。
- 抽查人員名單的姓名、家別、分組與專屬連結一一對應。
- 完整專屬網址只交給本人，公開資訊中沒有小卡 token 或完整匯出清單。
- 一般首頁不建立訪客小樹；同卡跨手機能讀取相同進度，已配對卡片可直接編輯個人內容。
- 分組已發布，集合位置正確，活動前無法提前取得分組資料。
- 活動資訊在動畫結束後仍可閱讀；影片尚未上架時沒有空白播放框。
- 用一般訪客身分及手機實測專屬連結，並保留現場備用名單。
- 指定一位工作人員負責切換階段，另一位負責核對前台結果。
