# 載耶小屋・搖搖耶誕樹

2026-11-14 更新。此自架版本使用自己的 Node.js 伺服器與本機 SQLite；部署、帳號及備份方式見 [SELF-HOSTING.md](SELF-HOSTING.md)。

## 一張小卡，一個身分

每張 NFC 卡寫入不同的 `/t/{token}` 專屬網址。token 隨機產生，不能由卡套流水號推算；同一個網址連結活動內容、個人小樹、排行榜身分和紀念小卡編輯權。網址只交給本人收藏，勿當作公開分享連結；需要分享個人外部網站時，直接分享那個外部網址。

小卡編號不會因改名而改變。預設名稱使用 `#001` 這類卡號，持卡者可另設遊戲暱稱及個人顯示名稱。本人使用另一支手機開啟相同網址，仍會讀取同一棵小樹；進度不依賴訪客 Cookie。未帶 token 的一般首頁不建立新的 guest 玩家，無效或停用的卡片也不能增加成長。

## 四個入口與活動階段

主畫面依主辦設定切換：活動前為邀請動畫與直式預告，活動中為已開放的分組結果，活動後為紀念畫面與相簿入口。「活動」可查看日期、時間、地點；「搖樹」是個人養成與全站排行榜；「小屋」保留小卡門牌、小樹成長與紀念卡。

主辦在後台「活動總覽」最上方看到目前階段，點選「活動前／活動中／活動後」即可儲存，介面會顯示處理中及成功狀態。同一個小卡網址會隨階段更新，不必重寫 NFC 或再次感應。活動中的組別仍需先發布分組並開放揭曉。

## 音樂

背景音樂為自製的傳統《We Wish You a Merry Christmas》音樂盒編曲。點一下音樂按鈕後，40 秒音軌會循環播放。切換 App 畫面不中斷；開啟預告或切到其他應用程式時暫停，回來後恢復原先啟用的音樂。點按音效另有開關，製作紀錄見 `design/MUSIC.md`。

## 搖搖耶誕樹

1. 從自己的 NFC 專屬連結點「搖樹」，系統直接找到或建立該卡的小樹，以 `#卡號` 為預設名稱。無須先取名或註冊。
2. 想改名時點暱稱旁的編輯按鈕，填寫 2～16 字暱稱。改名不會建立另一位玩家，也不會重設進度。
3. 點「開啟搖搖」。手機若要求動作感測權限，允許後輕輕左右搖即可；也可點畫面按鈕讓樹長大。動作感測需要 HTTPS 與支援的瀏覽器。
4. 每次有效成長增加 2 公分，從 30 公分開始。樹會經過「小小樹苗、冒出新芽、枝葉初長、綠意成蔭、耶誕大樹、星光巨樹」六個階段，各有獨立手繪素材。
5. 「排行榜」按樹高排序，每頁 5 人；同高依建立時間與固定識別碼排序。排行榜顯示暱稱、卡號、樹高與名次，不公開報名姓名、家別或專屬網址。

畫面會區分待儲存與已儲存的成長。連線失敗會保留待送操作並重試，相同操作重送不會重複加分。離開遊戲或切到背景會停止感測，回來可再按開始。不同分頁的儲存會由伺服器檢查，前端不能提交任意樹高。

## 編輯與回顧

卡片啟用且已配對參加者時，持有專屬連結即可從「小屋」編輯名稱、簡介與個人 HTTPS 連結，無須登入或私人認領碼。個人名稱留白時會使用 `#卡號`；也可在原網址加上 `?edit=1` 直接編輯。後台仍須自己的管理員帳號登入。

活動後主畫面提供漂亮的紀念插畫、回顧文字和外部相簿按鈕。主辦只要填相簿網址即可；封面照片可留白。未填相簿時顯示整理中的訊息。個人外部連結由持卡者主動按下才會開啟，不會在進站時自動轉址。

## 資料與換卡

- 小樹存於本機 SQLite 的 `settings` 表，以卡片 ID 保存；舊訪客資料保留相容，但不建立新 guest 玩家，也不列入有效卡片排行榜。
- 小卡 URL 本身具有操作該卡的權限。卡套上的流水號可供辨識，完整隨機網址則請本人保管。
- 換卡請由工作人員核對身分、停用原卡並配對備用卡；個人頁與分組跟著參加者保留。小樹以卡片 ID 儲存，換到另一張卡時不會自動搬移舊卡進度。
- 舊合作遊戲資料保留相容；目前入口是個人養成，不需要邀朋友、加入房間或另建訪客身分。

## NFC 寫卡

從後台匯出正式 NFC 網址清單。每一列的流水號和完整隨機網址是一對：寫入該列網址，在卡套寫上相同流水號，再逐張感應核對正式網域與頁面卡號。已寫入的卡片繼續使用原網址，更新影片、階段、分組與相簿不需要重新寫卡。伺服器搬遷時另依部署文件處理網域與 token 保留。

## 驗證範圍

本輪需確認同卡跨瀏覽器進度、預設卡號與改名、無 token 不建立玩家、停用卡限制、token 個人編輯權及後台三階段切換。測試與 UI 驗收紀錄由各次驗證文件記載，不以舊版訪客測試數量代表新版結果。

先前已測過搖動辨識、成長重送與跨分頁佇列；實體手機的搖動靈敏度仍需現場確認。測試玩家及預覽圖中的成績只用於隔離測試環境。
