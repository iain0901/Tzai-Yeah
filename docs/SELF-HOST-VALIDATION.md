# 自架版驗證紀錄

2026-11-14，Windows、Node.js 24.16.0、Next.js 16.3.4。自架版使用本機 SQLite 與本站帳號，不使用平台登入標頭。所有操作測試使用隔離的測試資料與臨時帳號。

## 已執行

- `npm run build`：Next.js 正式建置、TypeScript、standalone 打包成功。圖像、音樂、遷移與初始化工具包含在產物中。
- `npm test`：71 項通過，涵蓋真實 SQLite 交易、綁定與分組發布、私密認領碼、搖樹限速與去重、跨分頁佇列、帳號角色、Cookie、CSRF、密碼雜湊與重設。
- `npm run test:http`：實際啟動 standalone 程序，透過 HTTP 驗證公開前台、靜態資源、登入／註冊、管理員與會員權限、偽造標頭拒絕、NFC 卡片綁定、分組揭曉、認領和個人頁、小樹與排行榜。
- HTTP 測試停止並重新啟動網站，確認卡片網址、帳號、登入工作階段、個人頁與樹高保留；登出後無法繼續取得管理資料。
- 初始化工具首次建立 150 張卡、獨立隨機登入密鑰與管理員；再次啟動保留原有代碼、密鑰和密碼雜湊。CSV 衝突整批回滾，匯出使用設定的正式網域。
- SQLite 線上備份包含 WAL 中已提交資料；離線還原驗證完整性及 migration ledger。缺少、損壞、不相容或來自較新版的備份在替換資料前被拒絕，既有資料庫保持不變。
- 瀏覽器確認 390 × 844 手機首頁保留固定畫面導覽，本站管理員登入後可開啟管理介面；1280 × 720 前台沒有頁面溢出。這是瀏覽器尺寸驗證，不等同真實手機感測器驗證。
- Docker Compose YAML、部署檔路徑、文件連結與 `git diff --check` 檢查通過。

## 驗證範圍

本機沒有 Docker daemon，因此沒有執行容器映像建置。Node.js 正式產物及完整 HTTP 操作已實測；容器、正式網域、HTTPS 憑證、實體 NFC 和手機動作感測器需在部署主機／實機確認。這次沒有更動原本的 Sites 線上版本。

私人交付的初始化資料保留原本 150 張卡的流水號與代碼，並建立新的本站管理員。它不是舊站完整資料庫的複本，不包含舊站帳號、參加者、分組或遊戲紀錄；測試資料也不在交付資料庫中。密鑰、密碼、NFC 清單與資料庫均未提交 GitHub。
