# 載耶網站｜實際操作驗收

此清單用於實機與正式環境驗收，不代表已執行通過。執行時記錄日期、環境、裝置、結果與處理人。使用測試參加者及備用卡，避免把測試資料混入正式分組。

## 入口與手機閱讀

- [ ] 在一般參加者沒有後台權限的瀏覽器開啟正式網站，確認符合預定的公開／登入流程。
- [ ] 用兩種不同手機感應兩張不同卡片，核對卡套流水號與前台卡號。
- [ ] 直式窄螢幕上無橫向溢出，主要文字和操作按鈕不被底部區塊遮住。
- [ ] 活動資訊動畫可跳過；日期、15:30 入場、16:00～22:00 及地點最終保持可讀。
- [ ] 手機「減少動態效果」開啟後仍可完成操作；按鈕沒有依賴動畫才能顯示。
- [ ] 慢速網路下仍可看見明確載入狀態或錯誤提示，不會顯示假分組結果。
- [ ] 無效網址、停用卡、未綁定卡與未分組卡各有可理解的處理方式。

## 預告與活動資訊

- [ ] 未設定影片時使用活動資訊畫面，沒有假播放按鈕或空白影片框。
- [ ] 設定實際直式 YouTube 網址後可主動播放，拒絕不支援的影片網址時有提示。
- [ ] 影片權限允許真實參加者播放，播放前後均容易找到活動資訊。
- [ ] 修改資訊後重新開頁能看到新內容；過去已開啟的頁面有可用的重新整理方式。

## 名單、分組與階段

- [ ] CSV 含繁體中文、同名不同家別、引號／逗號和零開頭卡號時可正確預覽。
- [ ] 錯誤組名、重複卡號、已綁他人的卡片及空白姓名不能造成半份名單匯入。
- [ ] 工作人員修改草稿後，前台仍顯示既有已發布版本。
- [ ] 發布後的組名、集合地點、提醒和人員配對一致。
- [ ] 揭曉關閉時，檢查前台請求的回應內容也沒有提前傳送該卡的組別。
- [ ] 活動中且揭曉開放後，各張卡顯示自己的已發布組別。
- [ ] 重新感應及重新整理不會重新分組，也不會強迫重看完整動畫。
- [ ] 臨時換組重新發布後，新結果可被參加者讀取，離線名單也重新匯出。
- [ ] 已發布後修改組名、移動卡片或刪除組別，各自符合介面提示及草稿／發布規則。

## 權限與個人頁

- [ ] 未登入訪客和一般持卡帳號均不能讀取後台完整名單或執行管理操作。
- [ ] 只知道卡片網址的人不能直接修改個人頁。
- [ ] 本人登入並使用私人認領碼後，可以編輯自己這張卡的個人內容。
- [ ] 錯誤、失效或已使用的認領碼不能取得編輯權。
- [ ] 認領碼重新發放或擁有者重設後，舊憑證和舊帳號的效果符合操作提示。
- [ ] 兩個不同帳號不能同時成功認領同一位參加者；其他卡片的內容也不能被改動。
- [ ] 非 HTTPS 及帶帳密的網址無法儲存；表單文字不會當作 HTML 執行。
- [ ] 活動前與活動中即使已設定個人連結，也仍能使用活動功能。
- [ ] 活動後以回憶畫面與外部相簿按鈕為主；個人連結需在小屋主動開啟，不自動跳轉。
- [ ] 開著同一個專屬網址時，後台切換活動階段，約 15 秒內更新主畫面；正在玩遊戲或輸入暱稱時不失焦。
- [ ] 停用舊卡並更換備用卡後，舊卡無法繼續取得原來的受限卡片資料，新卡連到正確參加者。

## 現場與維護

- [ ] 在正式環境完成約 150 人需求的合理並行請求測試，記錄失敗率和回應時間；另用現場網路測試手機。
- [ ] 測試過程沒有把影片流量誤算成單純 API 查詢；預告按需載入。
- [ ] 離線名單在斷網狀態可開啟，欄位與已發布版本一致，沒有把私人認領碼外流。
- [ ] CSV 使用試算表開啟時，使用者輸入的公式樣式文字不會執行成公式。
- [ ] 工作人員報到和取消報到可反映正確狀態，掃卡不會自動冒充報到。
- [ ] 重新啟動服務或重新發布程式後，正式資料仍保留。
- [ ] 正式資料庫遷移、管理員設定、長期網域及回顧素材的維護責任已交接。
